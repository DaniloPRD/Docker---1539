# Projeto Spring MVC com Thymeleaf

Este projeto é um exemplo de aplicação Spring Boot com Thymeleaf, criado para a disciplina de Programação III.

## Como executar com Docker

### Passos:

1. Clone o repositório:
   ```bash
   git clone https://github.com/seuusuario/seurepo.git
   cd seurepo
   ```

2. Construa a imagem:
   ```bash
   docker build -t spring-thymeleaf-app .
   ```

3. Execute o container:
   ```bash
   docker run -p 8080:8080 spring-thymeleaf-app
   ```

4. Acesse no navegador:
   ```
   http://localhost:8080
   ```
